### Основные сценарии работы

1. **Создание заявки.** Сотрудник отдела снабжения создаёт заявку, указывая заголовок, материал и описание. После создания заявке присваивается номер и устанавливается статус `New`.
2. **Назначение исполнителя.** Руководитель или уполномоченный сотрудник назначает специалиста для обработки заявки. При назначении статус остаётся `New`.
3. **Изменение статуса.** Назначенный специалист может перевести только свою заявку из статуса `New` в `InProgress`. Другие пользователи не могут выполнять это действие.

### Архитектура системы

Система использует трёхузловую архитектуру:

1. **Frontend:** Vue 3 + Vite — пользовательский интерфейс.
2. **Backend:** ASP.NET Core — обработка запросов и бизнес-логика.
3. **Database:** PostgreSQL — хранение данных системы.

### Основные сущности

- `PurchaseRequest` — заявка на закупку материалов.
- `NomenclatureItem` — справочник материалов.
- `AppUser` — пользователь системы.

В модели данных также предусмотрены связи между заявками, пользователями и материалами.

### Статусы заявок

Для заявок предусмотрены следующие статусы:

- `New` — новая заявка.
- `InProgress` — заявка находится в работе.
- `Closed` — заявка закрыта.
- `Cancelled` — заявка отменена.

### Основные операции API

- `GET` — получение списка заявок и информации об отдельной заявке.
- `POST` — создание новой заявки.
- `PATCH` — назначение исполнителя.
- `PATCH` — изменение статуса заявки.
