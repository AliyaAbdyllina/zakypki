## 1. Цель

В том же проекте поднять клиент на Vue 3 и JavaScript так, чтобы по README открывались три экрана: список заявок, создание заявки и вход, обычно на `http://localhost:5173`.

## 2. Что сделано

1. Каркас создан мастером `npm create vue@latest` в папке `frontend`: JavaScript, без TypeScript, JSX, Vue Router, Pinia и тестов; ESLint оставлен, методичка это допускает.
2. В `frontend/src/App.vue` три экрана переключаются через `ref` и `v-if` / `v-else-if` / `v-else`.
3. Список выводит две демонстрационные записи через `v-for` с `:key="item.id"`.
4. Форма создания содержит `title`, `materialId`, `description`. Имена полей взяты из `docs/data-model.md`: вместо учебного `siteId` используется `materialId`.
5. Форма входа содержит логин и пароль.
6. В корне создан `.gitignore`, в `README.md` добавлены команды запуска.

Формы являются макетами. По кнопке показывается сообщение, что данные не сохранены или не проверяются; страница не перезагружается.

Критерий 1 ЛР1 («Создать объект») закрывают поля `title`, `materialId`, `description` и кнопка «Создать». На этом этапе это только разметка, заявка не сохраняется.

На этом этапе проверка полей не входит в задание: она появится в ЛР5. Проверено поведение макета.

| Что сделали | Ожидание | Факт |
|-------------|----------|------|
| Ввели заголовок `abc` и нажали Enter | страница не перезагружается | не перезагрузилась, заявка не создана, показано: «Это макет: заявка не сохранена. Сохранение появится в ЛР5.» |
